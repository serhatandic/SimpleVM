# Contributing to SimpleVM

Thanks for taking the time to help improve SimpleVM.

## Issues are welcome

Use GitHub Issues for:

- Reproducible bugs
- Compatibility reports for Linux installers
- Focused feature requests
- Documentation corrections

Before filing a bug:

1. Search existing issues.
2. Reproduce it with the latest `main` branch.
3. Include the macOS, Xcode, UTM, QEMU, and guest versions.
4. Include the smallest useful log excerpt.
5. Remove passwords, VM contents, personal paths, and other sensitive data.

## Code pull requests are closed

SimpleVM is source-available under the PolyForm Noncommercial License 1.0.0.
To keep ownership and commercial licensing rights centralized, unsolicited
code pull requests are not accepted at this stage.

Please open an issue before doing implementation work. A public issue or
discussion does not grant permission to submit code for inclusion.

## Security reports

Do not disclose vulnerabilities in a public issue. Follow
[SECURITY.md](SECURITY.md) instead.
